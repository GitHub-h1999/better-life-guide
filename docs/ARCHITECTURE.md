# 架构与内容同步

## 数据流

原书 Git 仓库 → `scripts/sync-content.mjs` → `src/data/content.json` → Vue 页面 → Vite 构建 → GitHub Pages。

Vue 3 与 TypeScript 实现界面；Node 脚本读取 Markdown，不依赖线上内容 API。数据与页面同一版本发布，页面显示对应的上游提交及日期。日期是上游最后提交时间，不代表实际同步执行时间。

## 解析契约

从 `book/NN-*.md` 自动发现章节。解析一级标题和 `### N. 标题` 条目，保留成本、说人话、收益、证据等级、来源、备注，多行字段保留换行。证据等级允许 `C（争议）` 等注释，完整注释仍展示。

缺少必要字段、未知等级、重复编号、重复身份、缺章节、总条目数比当前快照下降超过 10% 或上游许可证变化都会停止同步。输出先写临时文件，再重命名，避免本地生成半份数据。10% 保护是异常检测，不是完整性数学证明；合理的大规模删改仍需人工核对。

## 收藏身份与迁移

使用归一化标题的 SHA-256 前 20 位作为身份，条号变化不会影响收藏。同名条目会停止同步，等待调整策略。标题变化时，只有同章节、字段正文完全相同的唯一候选才生成身份迁移。迁移表随数据快照累计保存。

标题和正文同时变化或条目被删除时，收藏可能不能自动迁移；浏览器保留未识别身份并显示提示，不猜测新条目。迁移不承诺识别所有语义改写。

## 原文展示与安全

原文通过 marked 转 HTML，再经 DOMPurify 净化。重要备注默认显示，避免折叠掉适用条件。原文链接固定到本次同步提交，方便核对网站所展示的版本。证据标签、免费标签只沿用上游标注，不自行添加收益数字或计算评分。

## 浏览器数据

`blg-saved` 存收藏身份数组；`blg-progress` 存最近进入阅读视区的条目身份；`blg-theme` 存浅色或深色偏好。写入失败时页面提示。没有登录、统计埋点或云端收藏接口。

## 列表规模

全文搜索匹配完整快照，界面每次展示20条，可继续加载；避免一次生成数百份 Markdown DOM。深链接会扩展展示范围以包含目标。全书快照目前仍随JS加载，大包限制见验证记录。
