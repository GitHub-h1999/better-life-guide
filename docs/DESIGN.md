# 界面设计：留白 / Paper

首套风格是「留白」：暖白纸面、深灰正文、少量蓝色强调，侧栏稍深于阅读区。大标题使用系统宋体/衬线字体，正文使用系统无衬线字体；没有外部字体请求、渐变插画或大幅装饰。

## 信息与视觉层级

首页左侧以标题和阅读入口建立层级，右侧以三行简洁的主题目录引导，不再放植物插画和三张彩色卡片。阅读区改为连续纸面，使用细线与条号分隔建议，避免一层层卡片包裹。

每条：小号证据/成本标记 → 标题 → 简明结论 → 完整备注 → 按需展开的成本、研究和来源。备注保留完整可见，浅底提示与正文在视觉上区分。正文行距2倍，阅读栏限制宽度。收藏、分享和展开统一使用 SVG 线性图标。

## 风格与显示模式

「阅读外观」提供当前风格和浅色/深色显示模式。风格与显示模式独立：留白也有对应深色配色。第一版只实现留白，不展示尚未实现的其他风格。

- `src/styles/paper.css`：留白风格的配色、字体、圆角和阴影令牌。
- `src/style.css`：共用布局与响应式规则，通过令牌取值。
- HTML 的 `data-style` 选择风格，`data-theme` 选择浅色/深色。
- `blg-style` 保存浏览器风格偏好；未知风格回退为留白。

后续新增风格时，新建独立令牌文件并加入 `availableStyles`。若布局也需要变化，可用 `[data-style=...]` 增加明确的样式覆盖。搜索、收藏、正文数据及同步脚本不复制。

## 移动端

800px及以下：目录改抽屉，底部固定探索/目录/收藏/继续读导航。560px及以下：搜索独占一行，首页主题目录排列到标题下方，正文缩小页边距，提示从横排改竖排。360px及以下进一步收紧边距。

手机底栏考虑安全区，条目定位留出顶部搜索区域。触控按钮、键盘焦点和展开状态可辨识，Escape 可关闭目录/外观面板；减少动态效果偏好禁用过渡。

## 布局预览

`public/design-preview.html` 是独立的开发验证页，不进入用户导航。可在320/390/768/1440px iframe中查看真实断点布局。它只模拟视口宽度，不能代替iOS/Android真机、系统字体与触摸行为测试。
