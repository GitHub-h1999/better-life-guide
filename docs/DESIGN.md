# 界面设计

以适合中文长文阅读的安静界面为目标：浅暖背景、森林绿强调色、清晰标题层级和适度留白。首页植物图形由 CSS 绘制，不依赖图片或外部字体。

## 信息顺序

标题 → 少量标签 → 说人话 → 完整备注 → 可展开的成本、研究数据与来源。备注不隐藏；不展示多枚重复的成本标签。首页提供健康、时间、金钱入口，完整章节目录始终可达。

## 响应式规则

- 宽屏：固定章节侧栏，正文限宽，顶部搜索。
- 800px 及以下：侧栏变抽屉，增加探索、目录、收藏、继续读底栏。
- 520px 及以下：搜索独占一行，主题入口保持紧凑，阅读卡片减少边距。
- 底栏考虑 `safe-area-inset-bottom`；正文底部留足空间。
- 条目锚点留出顶栏位置；触控按钮、键盘焦点和展开状态可辨识。
- 深浅主题同步界面色彩；减少动态效果偏好关闭过渡。

首版不添加大面积动效、登录弹窗或打卡任务，以阅读和查找为核心。
